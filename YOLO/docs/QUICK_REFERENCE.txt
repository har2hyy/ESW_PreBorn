🚀 THREE-COMMAND DEPLOYMENT
  
  1. Convert ONNX → DLC

  2. Setup QIDK Device
     $ ./setup_qidk_device.sh
     
  3. Run on NPU
     $ ./remote_npu_pipeline.py --image photo.jpg --dlc best_yolo_int8.dlc

⚙️  MANUAL CONVERSION (if needed)

  Step 1: ONNX → FP32 DLC
    $ snpe-onnx-to-dlc \
        --input_network best_simplified.onnx \
        --output_path best_yolo_fp32.dlc \
        --input_dim images 1,3,1024,1024

  Step 2: FP32 → INT8 DLC
    $ snpe-dlc-quantize \
        --input_dlc best_yolo_fp32.dlc \
        --output_dlc best_yolo_int8.dlc \
        --input_list calibration_list.txt \
        --enable_htp \
        --use_enhanced_quantizer

  Step 3: Verify
    $ snpe-dlc-info --input_dlc best_yolo_int8.dlc

================================================================================

🧪 TESTING OPTIONS

  Option 1: Test on PC (CPU)
    $ python test_dlc_on_pc.py best_yolo_int8.dlc
    → No NPU required
    → Expected: ~11 detections, 300-500ms
  
  Option 2: Test on QIDK NPU
    $ ./remote_npu_pipeline.py \
        --image test.jpg \
        --dlc best_yolo_int8.dlc \
        --runtime dsp
    → NPU required
    → Expected: 9-11 detections, 50-100ms ⚡

================================================================================

🎮 RUNTIME OPTIONS

  --runtime dsp   → NPU/HTP (fastest, 50-100ms) ⭐ RECOMMENDED
  --runtime gpu   → GPU (medium, 150-200ms)
  --runtime cpu   → CPU (slowest, 300-500ms)

🔧 TROUBLESHOOTING

  Issue: snpe-onnx-to-dlc not found
  Fix:   export PATH=$SNPE_ROOT/bin/x86_64-linux-clang:$PATH

  Issue: adb device not found
  Fix:   adb kill-server && adb start-server && adb devices

  Issue: Low INT8 accuracy
  Fix:   Increase calibration images (300+)
         find . -name '*.jpg' | head -n 300 > calibration_list.txt

  Issue: NPU execution fails
  Fix:   Try GPU first: --runtime gpu
         Check logs: adb logcat | grep SNPE
