🚀 DEPLOYMENT STEPS:

REQUIRED (5 minutes):
  1. Enable Email/Password auth in Firebase Console
  2. Create user account (e.g., admin@preborn.com)
  3. Add clientEmail to database: config/clientEmail
  4. Deploy database rules: firebase deploy --only database
  5. Deploy hosting: firebase deploy --only hosting

OPTIONAL (Email notifications - 10 minutes):
  6. Install functions: cd functions && npm install && cd ..
  7. Configure Gmail: firebase functions:config:set gmail.email/password
  8. Deploy functions: firebase deploy --only functions
  9. (Requires Blaze plan for Cloud Functions)
