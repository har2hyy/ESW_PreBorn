💡 IMPORTANT NOTES
═══════════════════════════════════════════════════════════════════════

⚠️  Depth Map is RELATIVE (not metric):
   • The depth_anything_v2 model outputs relative depth
   • Values are not in meters, just relative ordering
   • To get metric depth, you need to scale/align it

✅ To Get Metric Depth:
   Option 1: Use a known reference object
      • If you know an object in the image is exactly X meters away
      • Use that to scale the entire depth map
      
   Option 2: Use the checkerboard in the image
      • Capture image with checkerboard at known distance
      • Use align_depth_scale.py to calibrate
      
   Option 3: Stereo depth or LiDAR
      • Use hardware sensors for ground-truth metric depth
      • Train model to output metric depth directly
