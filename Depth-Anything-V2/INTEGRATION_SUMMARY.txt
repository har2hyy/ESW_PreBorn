Example 2: Measure Real Distance Between Workers
-------------------------------------------------
from pixel_to_3d import PixelTo3DConverter
import cv2

# Load calibration
converter = PixelTo3DConverter('camera_intrinsics.json')

# Load depth map
depth_map = cv2.imread('depth_metric.tiff', cv2.IMREAD_UNCHANGED)

# Get worker positions from YOLO
worker1_pos = (320, 240)  # pixel coordinates
worker2_pos = (450, 280)

# Get depths
depth1 = depth_map[worker1_pos[1], worker1_pos[0]]
depth2 = depth_map[worker2_pos[1], worker2_pos[0]]

# Convert to 3D
pos1 = converter.pixel_to_3d(worker1_pos[0], worker1_pos[1], depth1)
pos2 = converter.pixel_to_3d(worker2_pos[0], worker2_pos[1], depth2)

# Calculate real distance
distance = converter.horizontal_distance(pos1, pos2)
print(f"Workers are {distance:.2f} meters apart")

# Check safety threshold
if distance < 2.0:
    print("⚠️  SAFETY VIOLATION! Too close!")


Example 3: Convert Relative Depth to Metric
---------------------------------------------

    --roi 100 200 300 300 \
    --known-distance 5.0 \
    --output depth_metric.png

This aligns the relative depth map to real meters using a
known reference distance.


Example 4: Calibrate Your Own Camera
-------------------------------------
python calibrate_camera.py \
    --videos calibration_video_1.mp4 calibration_video_2.mp4 \
    --pattern-cols 7 --pattern-rows 9 \
    --square-size 0.02 \
    --output my_camera_intrinsics.json \
    --debug-images

Requirements:
   • Record videos of a checkerboard pattern
   • Move the checkerboard to different positions/angles
   • Ensure good lighting and sharp focus
   • Pattern size = number of internal corners

💡 TIPS FOR BEST RESULTS
═══════════════════════════════════════════════════════════════════════

1. Camera Calibration:
   ✓ Use 50-100 frames from different angles
   ✓ Ensure checkerboard is flat and well-lit
   ✓ Vary distances and orientations
   ✓ Aim for reprojection error < 0.5 pixels

2. Depth Estimation:
   ✓ Use same camera that was calibrated
   ✓ Don't change zoom or focus settings
   ✓ Good lighting improves accuracy
   ✓ Closer objects = better accuracy

3. Metric Depth Alignment:
   ✓ Choose a planar reference region
   ✓ Measure reference distance accurately
   ✓ Use median instead of mean for ROI depth
   ✓ Verify alignment with known objects

4. Safety Monitoring:
   ✓ Use horizontal_distance() for ground-level checks
   ✓ Set appropriate safety thresholds (e.g., 2m)
   ✓ Account for measurement uncertainty (±10-20cm)
   ✓ Validate with manual measurements
